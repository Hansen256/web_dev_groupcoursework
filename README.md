# Explore Uganda - Tourism Website

A responsive tourism website showcasing Uganda's top destinations and tour packages.

## Quick Start

1. Open `html/index.html` in your browser
2. Navigate through the site using the menu
3. Click on images in the gallery to view them in fullscreen
4. Fill out the contact form to inquire about tours

## Features

- **6 Pages**: Home, About, Destinations, Gallery, Packages, Contact
- **7 Destinations**: Queen Elizabeth, Lake Victoria, River Nile, Kidepo Valley, Lake Mburo, Bwindi, Murchison Falls
- **6 Tour Packages**: From $650 to $1600
- **Interactive Gallery**: Click images to view in lightbox
- **Form Validation**: Contact form with error checking
- **Mobile Responsive**: Works on all devices
- **Professional Footer**: Business info, hours, and quick links
